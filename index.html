Sobre el Proyecto GEMA MX

Oncología de Precisión y Ciencia de Datos en México

Nuestra Misión y la Problemática en México

En México, el cáncer de mama se ha consolidado como la principal causa de muerte por tumores malignos en mujeres. Un obstáculo crítico en la clínica es la detección de variantes genéticas de "Significado Incierto" (VUS), mutaciones raras cuya relación con la enfermedad aún no está documentada, lo que impide diagnósticos certeros y tratamientos personalizados.

GEMA MX responde a este desafío integrando Inteligencia Artificial avanzada. Mediante el uso de AlphaFold para el modelado de proteínas y simulaciones de docking molecular, este pipeline permite visualizar cómo un fármaco se acopla a un gen mutado, proporcionando evidencia estructural para reclasificar variantes y, en última instancia, identificar terapias dirigidas que pueden salvar la vida de miles de mujeres mexicanas.

API del GDC — Genomic Data Commons

Referencia técnica de la API utilizada para descargar los datos de mutaciones somáticas del proyecto TCGA-BRCA · NCI / NIH

¿Qué es el GDC?

El Genomic Data Commons (GDC) es la plataforma del Instituto Nacional del Cáncer (NCI / NIH) que centraliza y estandariza datos genómicos de cáncer a nivel mundial. Es el repositorio oficial del proyecto TCGA (The Cancer Genome Atlas), del cual se obtuvieron los 1,084 casos de cáncer de mama (TCGA-BRCA) que forman el dataset base de GEMA MX.

Portal GDC Documentación oficial API Search & Retrieval
Endpoints utilizados en GEMA MX
GET https://api.gdc.cancer.gov/ssm_occurrences
Descarga de mutaciones somáticas (SSM) del proyecto TCGA-BRCA. Filtra por cases.project.project_id=TCGA-BRCA y retorna campos como hugo_symbol, protein_change, sample_id y coordenadas genómicas. Paginado con size y from.
GET https://api.gdc.cancer.gov/cases
Metadatos clínicos por paciente: edad al diagnóstico, estadio tumoral, subtipo molecular (Luminal A/B, HER2, TNBC). Permite cruzar variantes con fenotipo clínico para priorización de relevancia.
POST https://api.gdc.cancer.gov/ssm_occurrences
Consultas con filtros complejos en formato JSON (operadores =, in, and). Se usa para filtrar variantes por tipo de mutación, gen específico o rango de frecuencia antes de descargar el dataset completo.
Parámetros de consulta principales
Parámetro Descripción
filtersObjeto JSON con condiciones de filtro
fieldsCampos a retornar (separados por coma)
sizeRegistros por página (máx. 10,000)
fromOffset para paginación
formatFormato de respuesta: JSON, TSV, CSV
Campos descargados para GEMA MX
ssm.consequence.transcript.gene.symbol ssm.consequence.transcript.aa_change ssm.consequence.transcript.consequence_type ssm.chromosome ssm.start_position ssm.end_position ssm.reference_allele ssm.tumor_allele case.case_id case.submitter_id
Ejemplo de query utilizado en ingest_data.py
Python · ingest_data.py 1,084 casos · TCGA-BRCA 
import requests, json

ENDPOINT = "https://api.gdc.cancer.gov/ssm_occurrences"

filtros = {
    "op": "and",
    "content": [
        {"op": "=", "content": {
            "field": "cases.project.project_id",
            "value": "TCGA-BRCA"
        }},
        {"op": "=", "content": {
            "field": "ssm.consequence.transcript.consequence_type",
            "value": "missense_variant"
        }}
    ]
}

params = {
    "filters": json.dumps(filtros),
    "fields": "ssm.consequence.transcript.gene.symbol,"
              "ssm.consequence.transcript.aa_change,"
              "ssm.chromosome,ssm.start_position,"
              "case.submitter_id",
    "format": "JSON",
    "size": 10000,
    "from": 0
}

response = requests.get(ENDPOINT, params=params)
data = response.json()["data"]["hits"]
Clasificación Clínica · ACMG/AMP

Variante de Significado Incierto

VUS — Variant of Uncertain Significance

Una VUS es una mutación genética para la cual la evidencia científica disponible es insuficiente para clasificarla de forma definitiva como patogénica o benigna. Esto no significa que sea inofensiva; simplemente que aún no existe consenso en la literatura.

Espectro de clasificación ACMG/AMP
Patogénica
Evidencia sólida de que la variante causa enfermedad. Se usa en decisiones clínicas y orientación genética. Ej: PIK3CA H1047R
Probablemente patogénica
Alta sospecha clínica pero la evidencia aún no es concluyente. Suele manejarse igual que patogénica en contexto clínico.
VUS — Significado incierto
La evidencia es contradictoria, insuficiente o simplemente no ha sido estudiada. Es la clasificación más común en proyectos TCGA de variantes raras o poco frecuentes. Requiere reclasificación periódica.
Probablemente benigna
Indicios de que la variante no causa enfermedad, pero sin confirmación total. No suele reportarse en consejería genética.
Benigna
Sin impacto funcional conocido. Presente en la población general a alta frecuencia. No relevante para el fenotipo tumoral.
¿Por qué importa en este pipeline?
Frecuencia en TCGA-BRCA
~60–70% de las variantes priorizadas son inicialmente VUS antes de análisis estructural
Reclasificación funcional
El análisis de RMSD y docking puede elevar una VUS a candidata terapéutica si altera el sitio activo
Herramientas in silico
SIFT, PolyPhen-2, CADD y este pipeline (AlphaFold + Vina) contribuyen a reclasificar VUS con evidencia computacional
Consenso requerido
ClinVar, LOVD y bases de oncología de precisión (OncoKB, CGI) integran evidencia multimodal para reclasificar
Nota clínica: Una VUS no debe usarse como base para decisiones terapéuticas directas sin evidencia funcional adicional. En este proyecto, las VUS se priorizan según frecuencia en cohorte, impacto estructural predicho (RMSD) y afinidad de docking, con el objetivo de generar hipótesis para validación experimental futura.
